GWAS-eQTL Mendelian Randomization Pipeline

A local end-to-end workflow for GWAS retrieval, GTEx eQTL matching, Mendelian Randomization, and optional GWAS association mapping from a DEG file.

Python + uv launcher Rscript backend PLINK LD support GTEx tissue matching Optional DEG association layer
What It Does

Pipeline Flow

1. Read your inputs Disease name, biosample, DEG file, and local reference data are loaded.
2. Retrieve GWAS data The code searches GWAS-DATABASE-FTP.tsv and selects a matching GWAS study.
3. Match GTEx tissue A GTEx eQTL tissue file is selected from GTEx_eQTL_TISSUE_EXPRESSION/.
4. Run MR in R mr_pipeline.R executes the MR workflow using PLINK where needed.
5. Build reports The pipeline writes MR outputs, summary tables, and an HTML report.
6. Optional association step If gwas-latest-all-assoc.tsv is valid, DEG-to-GWAS association runs too.

Run It

PowerShell Command

Use this when running from PowerShell.

.\run_pipeline.ps1 "C:\Users\shahr\Downloads\GWAS-eQTL Mendelian Randomization Pipeline\Chronic_Kidney_Disease_100_genes (1).csv" -Disease "Chronic Kidney Disease" -Biosample "Kidney Tissue"
Run It

Command Prompt Command

Use this when running from plain cmd.

run_pipeline.cmd "C:\Users\shahr\Downloads\GWAS-eQTL Mendelian Randomization Pipeline\Chronic_Kidney_Disease_100_genes (1).csv" --disease "Chronic Kidney Disease" --biosample "Kidney Tissue"

PLINK

Reference Prefix

These three files must share the same prefix:

plink\1000G_EUR_hg38.bed plink\1000G_EUR_hg38.bim plink\1000G_EUR_hg38.fam
Backend Map

Important Code Modules

File Role
gwas_mr/defaults.py Resolves local reference data paths from this repository root.
gwas_mr/pipeline.py Main orchestrator for preflight, GWAS retrieval, MR, and optional association.
gwas_mr/retrieval.py GWAS selection, download/cache logic, and GTEx tissue matching.
gwas_mr/mr_runner.py Launches the R backend and passes PLINK settings.
gwas_mr/mr_pipeline.R Runs the Mendelian Randomization workflow itself.
gwas_mr/report.py Builds the HTML MR summary report.
gwas_mr/gwas_association/pipeline.py Runs the optional DEG-to-GWAS association workflow.
Outputs

What You Get

  • GWAS_Data_Output/ for retrieved GWAS study folders and cache
  • pipeline_output_test/<trait>/ for MR outputs
  • MR_PIPELINE_REPORT.html inside the trait output folder
  • gwas_association/ output folder if the association branch runs
Git Safety

Ignored In Git

The local .gitignore now excludes large reference data, outputs, PLINK assets, local environments, and .env so those files do not get pushed accidentally.
